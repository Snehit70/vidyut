# Manrope is the product typeface

> Status: accepted

Vidyut uses Manrope as its single product typeface across headings, body text,
labels, controls, and operational data. It replaces the current Plus Jakarta
Sans direction because the design system is moving toward a more geometric,
precise utility character while retaining warmth. The typeface must be locally
packaged, mapped to Material type roles, limited to deliberate weights, and
tested with Android text scaling.

Roboto remains the platform reference for sizing and hierarchy, not a second
product font. The system must not introduce a second type family merely to
create visual contrast.
